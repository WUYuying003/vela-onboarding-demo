# Vela · AI Agent Onboarding Demo

火山引擎产品设计师测试题的高保真可交互原型，由吴瑜英（WUYUYING）设计与制作。

## 交互范围

- 通过自然语言、模板、资料和数据连接发起首个真实任务
- Agent 反向 Brief：确认目标、证据、交付物、范围与执行边界
- 计划可见与数据权限分级确认
- 可追溯执行进度与模拟失败恢复
- 可编辑结果工作台、证据定位、继续追问、导出和保存模板
- 桌面端与移动端响应式适配

## 本地运行

```bash
python3 -m http.server 4173 -d dist
```

浏览器打开 <http://localhost:4173>。
